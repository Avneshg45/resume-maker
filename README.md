# 🚀 AI Resume Maker

Ek modern web application jo Next.js aur Gemini AI ka use karke professional aur ATS-friendly resume banane mein madad karti hai.

## 🛠️ Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS / Standard CSS
- **AI Integration:** Google Gemini API
- **Deployment:** Vercel

## ✨ Features
- Real-time preview aur editing.
- AI-powered content generation aur suggestions.
- Clean aur responsive user interface.
